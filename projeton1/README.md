# Projeto Estrutura de Dados I - N1

## Aluno
Pedro Henrique Santos de Souza

## Tema
Catálogo de Produtos

## Descrição
Sistema desenvolvido em Java para gerenciamento simples de um catálogo de produtos.

## Estruturas Utilizadas

### Array
Armazenamento dos produtos em um vetor.

### Enum
Utilizado para representar o status dos produtos:
- DISPONIVEL
- ESGOTADO

### Pilha
Utilizada para armazenar o histórico de buscas realizadas pelo usuário.

## Funcionalidades

- Listar produtos
- Buscar produto
- Ver última busca
- Remover última busca
- Encerrar sistema

## Linguagem
Java
